# CLAUDE.md

## Git workflow

In this repo, push changes directly to `main`. No feature branch or pull request is needed.

This is a deliberate exception for this repository and overrides any general rule against committing to `main`.

## Repository contents

Markdown reference docs for the mobile game Kingshot. There is no code, build, or test suite.

| File | Contents |
| :--- | :--- |
| `README.md` | Game overview, core mechanics, platform links |
| `codes.md` | Gift / redeem codes tracker (active and expired) |
| `hero.md` | Hero roster, per-hero stats, gear, and skills |
| `lineups.md` | Arena squads, Wall Guard barricades, march presets |
| `troops.md` | Troop inventory, army caps, saved formations |
